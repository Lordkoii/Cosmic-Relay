# Security Policy

## Supported versions

Cosmic Relay is currently alpha software. Security fixes are applied to the latest public tester build; older alpha builds may no longer receive fixes.

## Reporting a vulnerability

Please do **not** publish sensitive security details, exploit steps, credentials, tokens, or proof-of-concept code in a public issue.

If GitHub Private Vulnerability Reporting is available for this repository, use it to report the issue privately.

If private vulnerability reporting is not available, open a minimal public issue titled **[Security] Request private contact** without including sensitive technical details. A private channel can then be arranged for the full report.

Please include, when possible:

- The affected Cosmic Relay version
- The affected Windows version
- A clear description of the issue and potential impact
- Reproduction conditions
- Whether the issue affects the distributed binary, update/release process, local settings, or another component

For ordinary bugs, media compatibility problems, or feature requests, use the normal GitHub issue forms instead.
